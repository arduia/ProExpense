# iOS App (placeholder)

SwiftUI shell for Finance Tracker. The KMP data-layer modules (`shared`, `core:*`, `feature:*`)
now build `iosArm64`/`iosSimulatorArm64` klibs, so the shared logic compiles for iOS — this
directory is still a placeholder until the SwiftUI shell + Kotlin/Swift interop bridging spike
(NativeCoroutines/Skie) starts.

See `docs/finance_tracker_product.md` for the target stack.
